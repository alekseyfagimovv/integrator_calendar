# 📅 Calendar Automator (Integrator Calendar)

Сервис для автоматизации планирования Google Calendar на основе пользовательских шаблонов и графика работы 2/2. Проект включает в себя асинхронный бэкенд на FastAPI и легкий веб-интерфейс для управления расписанием.

## 🚀 Основные возможности
- **Интеграция с двумя Google-аккаунтами:** Поддержка OAuth 2.0 и одновременная работа с двумя разными календарями.
- **Шаблонизация:** Настройка событий для рабочих, выходных и учебных дней через веб-интерфейс.
- **Генерация по графику 2/2:** Автоматическое заполнение календаря на основе All-day событий-якорей (например, "Работа 9-21").
- **Ручное управление:** Возможность принудительно перезаписать конкретный день или полностью очистить его (с защитой All-day событий и сна).
- **Защита от дубликатов:** Проверка на наличие одинаковых событий перед созданием.

## 🛠 Технологический стек
- **Язык:** Python 3.13+
- **Фреймворк:** FastAPI, Uvicorn
- **Менеджер пакетов:** `uv`
- **Сетевые запросы:** `httpx` (асинхронно)
- **Фронтенд:** Vanilla HTML/JS, Jinja2
- **API:** Google Calendar API v3
